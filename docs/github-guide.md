# GitHub이 처음인 사람을 위한 안내

이 저장소는 대회의 공식 공유소입니다. 코딩 지식 없이도 아래 4가지만 알면 충분합니다.

## 1. 보기 — 그냥 클릭하면 됩니다

- 폴더/파일을 클릭하면 내용이 브라우저에서 바로 보입니다. `.md` 문서는 웹페이지처럼 렌더링됩니다.
- 규칙이 궁금하면 [MANUAL.md](../MANUAL.md), 트랙이 궁금하면 [track/README.md](../track/README.md)부터 여세요.

## 2. 다운로드 — Releases에서 받으세요

- 저장소 메인 페이지 우측의 **Releases** → 최신 버전 → `Assets`의 zip 다운로드.
- 초록색 `Code` 버튼 → `Download ZIP`으로 전체를 받을 수도 있지만, **Releases 쪽이 "검증된 배포 시점"이라 안전합니다.**
- git을 안다면: `git clone https://github.com/<owner>/istech-it-arena.git` 후 업데이트는 `git pull`.

## 3. 알림 받기 — Watch (꼭 해두세요)

- 저장소 우측 상단 **Watch → All Activity** 를 누르면 규칙 변경·새 릴리즈·이슈 답변이 이메일/알림으로 옵니다.
- 팀당 최소 1명은 Watch를 켜두는 것을 권장합니다.

## 4. 이슈 올리기 — 질문·제보는 전부 여기로

1. GitHub 계정이 없으면 [github.com](https://github.com)에서 무료 가입 (학교 이메일 추천).
2. 상단 **Issues** 탭 → 초록색 **New issue** 버튼.
3. 종류 선택 (질문 / 파일·트랙 문제 / 규칙 제안) → 템플릿의 빈칸을 채우고 **Submit**.
4. 답변이 달리면 알림이 옵니다. 추가로 할 말은 이슈 아래 댓글로.

팁:

- **스크린샷은 복사해서 글쓰기 칸에 붙여넣기(Ctrl/Cmd+V)** 하면 자동 업로드됩니다.
- 코드/로그는 백틱 3개(```)로 감싸면 보기 좋게 나옵니다.
- 내 질문과 비슷한 이슈가 이미 있는지 Issues 검색을 먼저 해보세요 (닫힌 이슈도 검색됨).

## 자주 묻는 것

**Q. 파일을 수정해서 올리고 싶어요.**
→ 직접 수정(push)은 운영진만 합니다. 바꾸고 싶은 게 있으면 이슈로 제안해주세요. Pull Request를 쓸 줄 안다면 PR도 환영합니다.

**Q. 트랙 파일이 새로 올라왔는지 어떻게 아나요?**
→ Watch를 켜뒀다면 알림이 옵니다. Releases 페이지의 날짜/버전으로도 확인할 수 있습니다.

**Q. 시뮬레이터에 어떻게 넣나요?**
→ [track/README.md](../track/README.md)의 "시뮬레이터별 사용법" 표를 보세요. 그래도 안 되면 이슈로.
