### 운영방식 & 세부규칙

| 동아리 | 의견 |
| --- | --- |
| MR | 시작순위: 예선전 또는 조종으로. 사고나면 사고더미로 두고 나중에 정리. 여러 바퀴. 피트인/아웃(할 일 명확히). 솔레노이드 같은 옆차 공격 금지 |
| ROD | 센서 시야 서로 안 가리게 (위 마커 보거나 아래 트랙만 보거나). 실격 기준 정의 필요. 사람 개입 가능하되 방해 안 되는 선, 특정 위치에서 재시작. **원격 비상정지 의무화**. 조명 무관 설계(ArUco, LiDAR 검출 벽, 쨍한 색) |
| Pinocchio | 차체 앞부분 기준 순위. 트랙엔 차체 2개씩만. 전체 동시 운영시 피트인/아웃. 연습주행 허용. 충돌/공격 규정. 차체 크기 규정. **예산 상한 빨리 결정** |
| MeKENic | 점수제: 완주 + 시간(짧을수록↑) + 미션 수행 |
| power-on | 벌칙시간 합산한 최종 시간으로 승부. **20초 이상 정체/역주행 시 30초 벌칙 + 가장 오래 머문 곳에서 재시작** (구체적!) |
| ISAAC | 점수제 (벌칙/랩/피트인 포함). 사람 개입 가능 + 강한 패널티 |
- 간단한 픽스: 차체간 공격 금지, 원격 비상정지 기능, 연습주행 허용, 여러바퀴를 진행, 순위판정은 차체 앞부분을 기준으로
- 디테일적인 논의
    - 차체크기: 15*20
    - 센서/감지 사양: 센서로 시야 서로 안가리게, 벽의 경우 명확한 색? LiDAR 가능한 정도…
    - 차끼리 판단: 이게 장애물인지 다른차인지 판단하기 위해 마커 혹은 특정 색을 포함(차의 뒷부분)
- 피트스탑
    - 하지말자
    - 하되, 의무가 아니고 / 가산점 혹은 랩타임 이득을 주자
    - 자유로운 피트스탑, 차량 문제 생기면 정비를 거기서, 그게 특정구간에 존재
- 트랙당 동시 차량 수:
    - 동시에: MR, MeKENic
    - 상관없다: pinocchio, power-on, ROD, ISSAC
- 승부 결정 방식: 시간제로 픽스
- 사고 처리
    - MR: 사고더미로 두고 특정 시간 이후 정리
    - power-on: 정체 혹은 역주행시 30초 벌칙, 제일 오래 머문 구역에서 재시작
    - ROD: 사람 개입 가능하고 특정 위치에서 재시작
    - ISSAC: 사람 개입이 가능하되, 강한 패널티 부과
    
    특정 다른 차량에 피해를 줄 행동()을 할때의 벌칙()부과, 이 과정에서 제일 오래 머문 구역에서 재시작을 하기. 
    ⇒ 패널티 시간을 정하기엔 디테일이 부족 / 달려야 할 바퀴수를 추가하면 어떨까요? 세부적인건 추후 더 픽스 필요
